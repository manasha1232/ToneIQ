ToneIQ — Quick Start (3 commands)
===================================
1.  cd toneiq/backend  && cp .env.example .env && npm install && npm run dev
2.  cd toneiq/frontend && cp .env.example .env && npm install && npm run dev
3.  Open http://localhost:5173 in your browser

All paid API keys are optional. The app runs fully with mocks.
See README.md for cloud deploy, cost estimates, and smoke tests.
